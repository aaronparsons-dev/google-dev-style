# Word list

Condensed from https://developers.google.com/style/word-list. Verdicts: **Use**, **Avoid**
(usually rewrite), **Don't use** (always rewrite). When a term isn't here, check the live page.

## Filler and hedging

| Term | Verdict | Write instead |
|---|---|---|
| please (in steps) | Avoid | Omit. Keep only to ask permission or apologize. |
| please note, note that | Don't use | State the information directly. |
| just | Avoid | Delete. If needed: only, instead, previously. |
| simple, simply | Avoid | Delete. |
| easy, easily | Avoid | Delete. |
| quick, quickly | Avoid | Delete. |
| basically, actually, obviously | Avoid | Delete. |
| in order to | Avoid | to |
| tl;dr | Don't use | To summarize |
| ymmv | Don't use | Your results might vary. |
| RTFM | Don't use | For more information, see … |

|---|---|---|

| utilize | Avoid | use |
| leverage | Avoid | use, build on |
| execute | Avoid | run |
| kill, abort, terminate | Avoid | stop, exit, cancel, end |
| impact (verb) | Avoid | affect |
| access (verb) | Avoid | see, edit, find, use, view |
| ensure, make sure | Avoid | a direct verb, or confirm |
| spin up | Avoid | create, start |
| surface (verb) | Avoid | expose, show |
| scale (alone) | Avoid | scale up, scale out |
| comprise | Don't use | consist of, contain, include |
| desire, desired, wish | Don't use | want, need |
| may (possibility) | Avoid | might |
| may (permission) | Avoid | can |
| could, would | Avoid | can |
| should | Avoid | can, must, or precise wording |
| shall | Avoid | must |
| will | Avoid | present tense |
| ssh, RDP (as verbs) | Don't use | connect by using SSH / RDP |
| unzip, untar, uncompress | Don't use | extract |
| screenshot (verb) | Don't use | take a screenshot |

## Connectives

| Term | Verdict | Write instead |
|---|---|---|
| e.g. | Don't use | for example, such as |
| i.e. | Don't use | that is |
| etc., and so on | Avoid | name the items, or introduce the list as non-exhaustive |
| and/or | Avoid | or, or name both |
| via | Don't use | through, by using, rephrase |
| vs. | Don't use | versus |
| vice versa | Don't use | spell it out, or conversely |
| once (meaning after) | Avoid | after |
| as, since (meaning because) | Avoid | because |
| while (contrast) | Don't use | although |
| with (ownership or means) | Avoid | that has; by using |
| above, below (position) | Don't use | earlier, preceding; later, following |
| above, below, under, higher, lower (versions) | Don't use | earlier, later |
| currently, presently, now, at present | Avoid | delete; write timelessly |
| soon, eventually, in the future | Avoid | delete, or give a date |
| new, latest | Avoid | delete, or give a version |
| timeframe | Avoid | period, schedule, deadline, when |
